# ROS2 理论与实践

ROS2 入门教程，共 6 章，涵盖环境搭建、通信机制、launch 与 rosbag2、坐标变换、可视化等内容。

## 如何阅读

- **本地阅读（推荐）**：双击 `_book/index.html`，左侧带完整侧边栏导航，可逐节跳转。
- **在线浏览**：`_book/` 下是编译好的静态 HTML，GitHub 不渲染 HTML，点进去只会显示源码，下载到本地打开才能正常阅读。
- **离线包**：`_book.rar` 为相同内容的压缩包。
